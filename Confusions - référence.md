# Confusions — sosies à ne pas mélanger

> Groupes d'espèces facilement confondues + **le critère qui tranche**. Sert au mode « sosies »
> du quiz (les mauvaises réponses sont tirées dans le groupe) et au feedback.
> Colonne *Espèces* = identifiants (stems) séparés par des virgules.

| Groupe | Espèces | Ce qui tranche |
|---|---|---|
| Ail des ours & sosies de printemps | ail_des_ours, muguet, arum, colchique | Froisser une feuille → **odeur d'ail** = ail des ours (comestible). Sinon **toxique** : muguet (feuilles engainantes, clochettes), arum (spathe), colchique (aucune feuille à la floraison d'automne). |
| Ombellifères : ciguë mortelle | cigue, cerfeuil, persil, carotte, egopode | Grande ciguë = **tige maculée de pourpre**, glabre, odeur désagréable (souris). Cerfeuil/persil : tiges vertes, odeur agréable. Dans le doute, **s'abstenir**. |
| Aulne / Noisetier | aulne_glutineux, noisetier | Aulne : feuille **tronquée ou échancrée** au sommet, petits **cônes** ligneux persistants. Noisetier : feuille en pointe, chatons + noisettes. |
| Chêne pédonculé / sessile | chene_pedoncule, chene_sessile | Pédonculé : **glands portés par un long pédoncule**, feuille quasi sessile (oreillettes). Sessile : glands collés au rameau, feuille à long pétiole. |
| Chêne pubescent / vert | chene_pubescent, chene_vert | Pubescent : **caduc**, dessous de feuille feutré-poilu. Vert : **persistant**, feuille coriace vernissée, gland très amer. |
| Érables champêtre / sycomore | erable_champetre, erable_sycomore | Champêtre : **petites** feuilles à 5 lobes obtus, rameaux parfois lièges. Sycomore : **grandes** feuilles dentées, port élevé. |
| Prunus sauvages | merisier, cerisier, prunellier, prunier | Merisier : grand arbre, **écorce à lenticelles horizontales** qui pèle en anneaux. Prunellier : **épineux**, petits fruits bleus (prunelles) très astringents. |
| Pins maritime / sylvestre | pin_maritime, pin_sylvestre | Maritime : aiguilles **longues et épaisses**, écorce crevassée sombre. Sylvestre : **écorce orangée** dans le haut, aiguilles courtes torsadées bleutées. |
| Sapin / Épicéa | sapin, epicea | Sapin : aiguilles **plates**, 2 bandes blanches dessous, cônes **dressés**. Épicéa : aiguilles **piquantes** (section carrée) sur pédicelle, cônes **pendants**. |
| Charme / Hêtre | charme, hetre | Mnémo « le Charme d'Adam c'est d'être à poil » : Charme = feuille **doublement dentée**, nervures marquées ; Hêtre = marge **ondulée à poils** (cils), non dentée. |
| Ortie / Lamier blanc | ortie, lamier | Ortie : **pique** (poils urticants), fleurs verdâtres en grappes. Lamier blanc (« ortie blanche ») : **ne pique pas**, fleurs blanches en gueule. |
| Rosettes velues : digitale toxique | consoude, digitale, bourrache | Avant floraison, rosettes proches. Digitale = **mortelle** (cœur) → fleurs tubulaires roses tachetées. Consoude/bourrache : poils rudes, fleurs en clochettes bleu-violet. |
| Argentés : argousier / chalef | argousier, chalef | Argousier : **épineux**, baies **orange** acides, feuilles étroites argentées. Chalef (olivier de Bohême) : peu ou pas épineux, petits fruits argentés. |
| Fabacées jaunes de lande | genet, ajonc | Ajonc : **très épineux** (rameaux en épines), fleur toute l'année. Genêt à balais : **sans épines**, rameaux verts souples. |
| Lande acide : myrtille / callune | myrtille, callune | Myrtille : feuilles caduques, **baies bleu-noir** comestibles. Callune (bruyère) : minuscules feuilles en écailles, fleurs roses, non comestible. |
| Bruyères de lande : callune et Erica | callune, bruyere-4-angles, bruyere-cendree | Callune : feuilles très petites en écailles, opposées et imbriquées ; Bruyère à quatre angles : feuilles en verticilles de quatre, fleurs roses en clochettes, milieux humides ; Bruyère cendrée : feuilles étroites en verticilles de trois, fleurs rose foncé à violettes, landes sèches. |
| Rubus : ronce / framboisier | ronce, framboisier | Ronce : mûres **noires** adhérentes, tiges arquées très épineuses. Framboisier : fruits **rouges** qui se détachent du réceptacle, tiges peu épineuses. |
| Malvacées : mauve / guimauve | mauve, guimauve | Guimauve : tout **velouté-blanchâtre**, milieux humides/salés. Mauve : plus verte, fleurs veinées, lieux rudéraux. |
| Lamiacées odorantes | menthe, melisse | Froisser : menthe = **odeur mentholée** ; mélisse = **odeur citronnée**. |
| Amanite mortelle vs comestibles | amanite_phalloide, russule_charbonniere, rose_des_pres | Phalloïde = **mortelle** : **volve** en sac à la base + **anneau** + lames blanches, chapeau verdâtre. Toujours dégager la base ! Rosé des prés : lames **roses puis brunes**, pas de volve. |
| Coulemelle vs jeunes amanites | coulemelle, amanite_phalloide, amanite_vireuse | Coulemelle : grande taille, **anneau coulissant**, pied **chiné** (zébré), **pas de volve**. Amanites : volve + anneau fixe → danger. |
| Bolets : satan toxique | cepe, bolet_bai, bolet_satan | Cèpe/bolet bai : chair qui **ne bleuit pas** fortement, pied clair. Bolet Satan : **pied rouge**, chair **bleuissante**, toxique. |
| Rosé des prés vs entolome livide | rose_des_pres, entolome_livide, clitocybe_blanc | Rosé des prés : **lames roses→brunes**. Entolome livide (toxique) : lames **jaunes puis saumon**, odeur farine. Clitocybe blanc : lames **blanches** décurrentes. |
| Amanites colorées | amanite_tue_mouches, amanite_panthere | Tue-mouches : chapeau **rouge** à flocons blancs. Panthère : chapeau **brun-beige**, anneau lisse, plus toxique. |
| Pollinisateurs : la mouche déguisée | abeille, osmie, bourdon, syrphe | Syrphe = **mouche** (2 ailes, gros yeux, **vol stationnaire**, ne pique pas) imitant l'abeille. Abeille/osmie/bourdon = hyménoptères (4 ailes) ; bourdon très velu ; osmie solitaire. |
